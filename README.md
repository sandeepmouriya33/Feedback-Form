# 📝 Feedback Form (API-Based Submission)

A lightweight, modern feedback form built with **HTML** and **CSS**, using a **JavaScript-based API integration** to store user feedback securely in a cloud database.

---

## 🚀 Features

- Responsive and clean UI
- Collects user's name, email, rating, and comments
- Submits data using cloud API
- No backend server or PHP needed
